# NexStock Brand Assets v1.1

Pacote oficial de identidade visual preparado para integração no Blueprint v1.1.

## Melhorias aplicadas

- transparência real nas cinco artes que antes continham o quadriculado gravado;
- conversão das marcas para PNG RGBA;
- logo empilhada sem slogan embutido, permitindo PT-BR, EN-US e ES via HTML/i18n;
- padronização de margens e enquadramento;
- aumento de resolução da logo principal, logo empilhada e mascote;
- nitidez e contraste ajustados de forma conservadora;
- hero scene otimizada em 1920×1080;
- ícones derivados para PWA e favicon;
- ícone maskable com área segura.

## Uso

Consulte `docs/brand-assets.json` para o local e a função oficial de cada ativo.

## Regras

1. Não distorcer proporções.
2. Não inserir slogan traduzível dentro das logos usadas pela aplicação.
3. No Dashboard, priorizar dados; mascote e hero ficam fora da área analítica principal.
4. Se uma imagem for decorativa e o nome/ideia já estiver em texto, usar `alt=""`.
5. O ícone PWA usa fundo #0B1120 para manter contraste previsível.
