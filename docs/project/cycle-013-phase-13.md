# Ciclo 013 — Fase 13

## Objetivo

Permitir que o usuário crie um nicho simples com campos próprios, sem alterar código.

## Entrega

- oito tipos oficiais de CustomFieldDefinition;
- criação e desativação dinâmica por workspace;
- chaves únicas, ordem, opções, obrigatoriedade e pesquisa;
- auditoria atômica das alterações;
- renderização no cadastro, edição e detalhes do produto;
- validação de valores no serviço de domínio;
- desativação sem apagar valores históricos;
- interface nos três idiomas.

## Gate

APROVADO quando a suíte completa e o pacote extraído forem validados sem falhas.
