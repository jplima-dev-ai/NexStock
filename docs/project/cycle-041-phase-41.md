# Ciclo 041 — NexLabels

NexLabels gera etiquetas locais imprimíveis para produto, lote, localização e
unidade serializada. Cada etiqueta mostra o NexCode e um código
`NXL|<NexCode>`, reconhecido pelo NexScan para abrir o produto correto.

Nenhuma etiqueta altera estoque ou exige rede. A prévia, o código em texto e a
impressão são operáveis por teclado e permanecem compreensíveis com NVDA.
