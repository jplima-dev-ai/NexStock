# Ciclo 042 — Mobile Operations 2.0

Em telas pequenas, NexStock apresenta uma navegação inferior própria com
Painel, Produtos, Ações, NexScan e Busca. Ações abre um diálogo nativo com
entrada, saída, scanner e busca; nenhum gesto é obrigatório.

O layout reserva espaço para a barra inferior e mantém tabelas em cartões. Os
atalhos reutilizam os fluxos locais existentes e preservam foco, teclado,
NVDA, três idiomas e funcionamento offline.
