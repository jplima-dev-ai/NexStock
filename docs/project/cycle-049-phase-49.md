# Ciclo 049 — NexReorder

NexReorder sugere considerar reposição quando a quantidade atual é menor ou
igual ao ponto de reposição: ritmo de saída de 30 dias multiplicado pelo lead
time, somado ao estoque de segurança. Lead time padrão é sete dias e estoque de
segurança padrão é o mínimo do produto quando não configurados. A sugestão
nunca compra, grava movimento ou altera estoque.
