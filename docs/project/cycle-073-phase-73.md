# Ciclo 073 — Regression Matrix

Fase 73. Release alvo: v2.0.0 Calm Intelligence. A matriz automatizada cobre
as combinações públicas críticas: cinco NexProfiles, os três idiomas, tema
claro/escuro, modos guiado/compacto, viewport desktop/tablet/mobile e provider
IndexedDB. Cada cenário cria seu próprio workspace, confirma o idioma e tema,
verifica a rota principal, a navegação mobile quando aplicável e a persistência
local.

O Supabase continua opcional e sem configuração pública; seu contrato de
provider permanece validado em teste unitário, sem backend, segredo ou rede.
Nenhuma migração, gravação de domínio adicional, alteração em backup/restauração
ou mudança no cache PWA foi introduzida.
