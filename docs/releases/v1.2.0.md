# NexStock v1.2.0 — Data Mobility

## Escopo

Esta release reúne as Fases 33 a 36 do blueprint v1.2: Import Center, Export Center,
NexBackup e snapshots locais. Os quatro fluxos trabalham por workspace,
pedem confirmação antes de gravar ou substituir dados e preservam a operação
local-first.

## Integridade dos dados

- importações só confirmam planos integralmente válidos;
- exportações filtram dados pelo workspace e protegem CSV contra fórmulas;
- NexBackup valida esquema, versão, referências, duplicidades e tamanho antes
  de qualquer restauração transacional;
- snapshots registram um ponto de segurança antes de importações e restaurações
  e não são incluídos no próprio backup.

## Compatibilidade

A versão atualiza o cache do shell para `1.2.0` sem migração destrutiva do
IndexedDB. Backups incluem sua versão de aplicativo e são rejeitados quando não
são compatíveis com a estrutura conhecida.

## Evidência de release

- gates automatizados das Fases 33, 34, 35 e 36;
- 154 testes unitários na base anterior à Fase 37;
- fluxos Chromium específicos de backup e snapshots aprovados;
- 1.023 mensagens equivalentes nos três idiomas;
- build e validação de GitHub Pages aprovados.
