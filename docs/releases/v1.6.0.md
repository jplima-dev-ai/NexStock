# NexStock v1.6.0 — Decision Lab

Integra as Fases 52 a 56: Scenario Lab com múltiplas variáveis, comparação
Real/A/B/C, Time Machine reproduzível, Inventory Digital Twin isolado e
Consequence Preview antes/depois para movimentações importantes.

Todos os recursos são locais, determinísticos e não persistem cenários. O
Digital Twin e as prévias nunca alteram o inventário real; a confirmação de uma
movimentação continua explícita e transacional.

## Gates integrados

1. Fase 52: múltiplas variáveis sem persistir.
2. Fase 53: Real, A, B e C comparáveis.
3. Fase 54: reconstrução histórica coerente.
4. Fase 55: Twin isolado do inventário real.
5. Fase 56: antes/depois em ações aplicáveis.
