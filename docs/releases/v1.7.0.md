# NexStock v1.7.0 — Trust & Integrity

Esta release integra a camada de confiança das Fases 60 e 61. Reversões geram
movimentações compensatórias auditáveis, sem editar ou apagar o registro
original. A Central de Privacidade e Dados torna explícitos o provider ativo,
localização dos dados, backup, snapshots, conexão e ausência de sincronização
automática local.

O NexStock permanece local-first, utilizável offline como PWA e compatível com
GitHub Pages. Não há backend obrigatório, segredo exposto na interface ou nova
dependência de runtime. A configuração opcional de provider remoto é descrita
sem revelar URL ou chave.
