# NexStock v2.0.0 — Calm Intelligence

Versão formalizada na Fase 78, após o release candidate `2.0.0-rc.1` e a
revalidação integral dos 40 critérios de aceite do blueprint v1.2.

## O que a versão entrega

O NexStock 2.0 reúne uma operação de estoque local-first com produtos,
movimentações auditáveis, mídia Blob, importação, exportação, NexBackup,
snapshots, scanner com fallback, etiquetas, inteligência determinística e
explicável, cenários isolados, integridade, privacidade e operação PWA offline.
O produto permanece estático para GitHub Pages e não exige backend, credencial
de cliente ou IA generativa.

## Checklist final

1. GitHub Pages, PWA, cache offline e persistência IndexedDB são validados.
2. Upgrade de v1.0, Settings, NexCopy, NexDesign, NexMotion e Product Media
   possuem evidência automatizada.
3. Import/export, backup/restore, scanner manual, labels e os componentes da
   camada de Intelligence possuem cobertura de serviço e fluxo.
4. Scenario Lab, Time Machine e Digital Twin permanecem não destrutivos.
5. NexShield, NexHealth, Audit Explorer e Reversal System preservam confiança,
   diagnóstico e histórico.
6. PT-BR, en-US, es, teclado, foco, reduced motion, zoom, contraste, E2E,
   axe, regressão visual, CI e documentação são exigidos pelo gate da Fase 78.

## Limites declarados

Esta versão não é ERP, sistema fiscal, contábil, pagamento, marketplace nem
SaaS obrigatório. Supabase permanece opcional; a demonstração pública opera
com IndexedDB no navegador.
