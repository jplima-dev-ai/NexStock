# NexStock v2.0.1 — manutenção corretiva

Esta manutenção preserva a arquitetura local-first da v2.0.0. Não cria fase
nova, não exige backend e não altera o formato de Product Media: as imagens
continuam como Blob no IndexedDB.

## Correções

- A restauração de backup com mídia usa uma única transação IndexedDB para os
  stores do workspace e `media`. Se uma imagem falhar, nada é confirmado.
- Para providers que não oferecem a mesma transação, o fluxo recupera a mídia
  anterior por operação compensatória e comunica claramente eventual falha.
- O gate canônico executa Fases 25–78, testes Node e E2E de forma idêntica no
  computador local, clone limpo e GitHub Actions.

## Compatibilidade

Backups existentes permanecem válidos. Backups sem mídia mantêm o
comportamento anterior; backups com mídia continuam validando limites,
referências e isolamento por workspace antes de qualquer escrita.
